# 구법 뱅머신·역A 분석

## 사용법

1. Session의 Impact source에서 **Bang machine — 구법 역A (1/1 octave)**를 선택하고 **Apply session**을 누릅니다.
2. Raw buffer를 측정시간 + 3초 이상으로 설정합니다. Start scan 후 3초 이상 기다리고, 배경소음을 측정한 후 가진 위치별로 Capture합니다. 하나의 Capture는 한 번의 충격을 대상으로 하며, 한 구간의 여러 충격을 자동으로 분할·평균하지 않습니다.
3. Rating에서 Evaluate를 누르면 **L'i,Fmax,AW**, 이동한 역A 기준곡선, 대역별 상회값, 상회값 합계가 나옵니다. 화면 결과를 기존 Export result로 저장할 수 있습니다.
4. 음원과 측정 대역폭은 세션 JSON에 저장됩니다. 고무공/뱅머신을 바꾸려면 현재 중량 측정값을 저장하고 Reset으로 비운 다음 선택합니다. 서로 다른 음원으로 얻은 측정값을 같은 세션으로 재해석하지 않습니다.

## 계산

- 대역: 1/1옥타브 63, 125, 250, 500 Hz.
- 각 대역의 원시 파형을 직접 필터링하고 Fast(125 ms) 최대값을 계산합니다. 서로 다른 시점의 1/3옥타브 최대값을 합산하여 1/1옥타브 최대값으로 대체하지 않습니다.
- 수음점별 레벨은 가진 위치 안에서 에너지 평균하고, 가진 위치 간에는 dB를 산술 평균합니다. 현재 공통 배경소음 보정은 이 평균 스펙트럼에 적용됩니다. 수음점별 개별 배경소음·반복 충격별 자료를 다루는 확장 기능은 포함하지 않습니다.
- 공유 배경소음은 1/3옥타브 Leq이며, 구법에서는 세 대역의 에너지를 합하여 옥타브 Leq로 변환합니다. 이 변환은 Fmax 변환과 구별됩니다.
- 역A 기준값은 아래와 같습니다. 1 dB씩 이동시키며 양의 상회값 합계가 8 dB 이하인 최저 곡선의 500 Hz 값을 평가량으로 사용합니다. 직접 측정 대역값은 기존 평가 엔진과 동일하게 0.1 dB로 반올림하여 비교합니다.

| 중심주파수 (Hz) | 63 | 125 | 250 | 500 |
|---|---:|---:|---:|---:|
| 기준값 (dB) | 83 | 73 | 66 | 60 |

신법 49 dB 판정 및 현장별 구법 적용 여부의 자동 판정은 수행하지 않습니다. 값과 편차표를 제공하는 구법 분석 모드입니다. 법정 성적서에는 프로젝트에 적용되는 고시·KS 판본의 측정점, 반복 횟수, 평균·배경 보정·수치 맺음 절차를 확인해야 합니다.

## 이전 파일

세션 스키마 3은 각 측정값에 fraction을 저장합니다. 이전 파일의 fraction이 없는 측정값은 종전 프로그램의 1/3옥타브 값으로 읽습니다. 예전 bang 세션을 열 수는 있으나, 이를 새 구법의 직접 옥타브 측정값으로 간주하여 평가하지 않습니다. 원시 파형으로 재분석하거나 다시 측정해야 합니다. 기존 ball/tapping 분석 경로는 유지됩니다.

## 출처와 검증 범위

- [대한건축사협회 게시 시험보고서](https://www.kira.or.kr/gongji_2013/2_%EB%94%B0%EB%94%B0%EC%8B%9C%EC%98%A8%EB%8F%8C_%EB%94%B0%EB%94%B0%EC%8B%9C%EC%98%A8%EB%8F%8C.pdf), 인쇄 33–34쪽: KS F 2863-2 중량충격음의 역A 표와 이동 절차. 공개 보고서의 값을 대조했으며, 해당 프로젝트의 KS 원문 판본 전체를 검증한 것은 아닙니다. 이 때문에 내장 곡선은 코드에서 verified=False로 남겨 두었습니다.
- [이용봉 외, 한국음향학회지 42(2), 143–151 (2023)](https://www.jask.or.kr/articles/pdf/M9M1/ask-2023-042-02-7.pdf): 종전 가진 위치 산술평균에 대한 논의 및 ISO 방식과의 구별.
- 신규 회귀 시험: 8 dB 한계, 1 dB 최저 이동, 500 Hz 앵커, 신법 판정 분리, 저장/복원, 구파일 차단, 위치 평균, 배경 Leq 합성, 직접 옥타브 Fmax, 비유한 입력 거부.
- 전체 비화면 시험 305개 통과. 전체 GUI와 실제 장비 시험은 이 실행 환경에서 수행하지 못했습니다.
