# 막대그래프·중량충격음 Fmax 개선 — 2026-09-08

## 적용

1. daqhats의 `fix/impact-meter-recovery-20260908` 브랜치로 서버를 업데이트하고 기존 설치 방식으로 PiSLM 서비스를 재시작합니다. 기존 현장 설정과 마이크 교정값은 보존합니다.
2. 이 압축파일의 PC 프로그램을 사용합니다. 실행 방법은 기존 `run.bat`와 같습니다.
3. Raw buffer를 측정시간 + 3초 이상으로 설정합니다. 스캔 시작 후 최소 3초 기다린 뒤 중량충격음을 측정합니다.
4. 실제 장비에서 교정음과 충격음으로 비교 측정한 뒤 현장에 적용합니다.

## 바뀐 동작

- 서버의 DSP 누락 직후 필터를 재설정하고 안정화될 때까지 불안정한 출력은 전송하지 않습니다. 누락 구간은 샘플 인덱스에 반영합니다.
- 화면은 짧은 갱신 간격의 최대값을 유지합니다. 각 채널·대역의 갱신이 0.75초 넘게 끊기면 오래된 값 대신 빈 표시와 대역 대기 메시지를 사용합니다. NaN/무한대가 막대를 오염시키지 않게 했습니다.
- 최종 중량충격음 Fmax는 원시 파형에서 대역 필터 → 제곱 → Fast(125 ms) 적분 → 전체 샘플 최대값 순서로 계산합니다. 화면의 20 Hz 출력으로 최대값을 결정하지 않습니다.
- 앞쪽 3초는 필터 초기화에만 사용하고 최종 측정시간에서 제외합니다. 측정 구간은 서버가 get_raw를 처리한 시점의 마지막 지정 시간입니다. GUI 클릭과의 정확한 동기 트리거는 아니며, 각 채널의 실제 샘플 구간과 주파수는 측정 note에 저장합니다.
- 파형 길이 부족, 비유한 값, 미교정(V) 채널, 누락 채널, 나이퀴스트를 넘는 대역은 오류로 처리합니다. 짧은 파형이나 실시간 표시값으로 자동 대체하지 않습니다.
- 서버 원시 버퍼 복사 중 새로운 샘플이 들어와도 파형의 시작 인덱스가 바뀌지 않습니다. PC에서도 다른 raw dump 응답이 현재 요청에 섞이지 않게 했습니다.
- 하드웨어 overrun은 원시 파형 무결성 오류로 표시합니다. 기존의 스트림 누락·과부하 유효성 검사는 보수적으로 유지하므로, 원시 계산이 가능해도 기존 무결성 검사에서 실패한 측정은 유효 판정을 받지 않습니다.
- 배경소음은 음원 선택과 관계없이 Leq로 계산합니다. 측정 도중 음원 종류를 바꾼 결과는 다른 종류의 세션에 저장하지 않습니다.

## 검증

- 서버 회귀 시험 5개 통과: DSP 누락 뒤 대역 복구, 샘플 인덱스 보존, 잘린 블록의 누락 위치, 버퍼 복사 동시성, 단일 프로세스 안정화.
- PC 기존 비화면 시험 275개와 신규 회귀 시험 18개 통과. 신규 시험에는 raw Fmax의 시간 이동 불변성, 정상 음압, 잘못된 파형·교정·응답 거부, 대역 표시 만료, overrun, 실제 GUI 작업 함수의 계산 경로가 포함됩니다.
- 51.2 kHz의 500 Hz / 10 ms 충격음 발생 시점을 50 ms 범위에서 바꿔도 새 Fmax의 차이는 1e-9 dB 미만이었습니다.
- 1 Pa peak / 1 kHz 정상음의 Fmax는 약 90.97 dB입니다.
- Qt/OpenGL 공유 라이브러리가 없는 실행 환경이라 전체 GUI 시험과 실제 화면 조작은 수행하지 못했습니다. GUI 작업 함수는 화면을 로드하지 않고 별도로 시험했습니다. 실제 MCC172/DT9837·현장 네트워크 시험은 아직 수행하지 않았습니다.

## 범위와 한계

이번 수정은 막대 표시의 DSP 복구와 중량충격음 최대값 계산 경로를 대상으로 합니다. 규정 적합성 인증이나 전체 평가 절차의 검증을 의미하지 않습니다. 필터의 IEC 등급 허용오차, 전체 KS/ISO 평가 절차는 별도 검증이 필요합니다. 서버의 실시간 필터는 기존 base-two, PC의 최종 파형 분석은 기존 PC 규약인 base-ten 대역을 사용하므로 표시값과 최종값에 차이가 날 수 있습니다. 다중 장치 ADC의 위상 동기 문제도 이 수정의 대상이 아닙니다.
